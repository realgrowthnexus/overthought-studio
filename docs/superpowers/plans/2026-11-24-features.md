# Features: video edits, channels grid, AI assistant. Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** The owner can edit a video's post time, title, caption and cover; the channels page is a card grid with
Edit; an AI assistant (bottom-left, the same Claude sign-in) answers questions about the live studio and proposes
actions that run only when the owner clicks.

**Spec:** `docs/superpowers/specs/2026-11-24-production-line-design.md` (§7.4, §7.4b A11, §7.6 #2 #3 #7)

## Global Constraints
- Every web mutation goes through `guard` (admin check) + zod. No secrets reach the client.
- The assistant runs in the worker (`claude_cli` via `llm.structured`, Sonnet/medium). Never the API fallback
  (`allow_fallback=False`). No tools. It answers in Roman Urdu or simple English, never Devanagari.
- Assistant actions come from a whitelist and are validated in the worker and again on click (the server action
  re-checks ids and state). **Nothing runs without a click.**
- Whitelist:
  - `pause_channel` / `resume_channel`;
  - `pause_studio` / `resume_studio`;
  - `make_video`;
  - `retry_job` / `cancel_job`;
  - `approve_video` / `reject_video`;
  - `publish_video`;
  - `set_post_time` / `clear_post_time`.
- A post time set by the owner is locked: the scheduler never moves or overwrites it. Setting one on a `ready`
  video also approves it.
- Cover = a frame (`cover_ms`). TikTok drafts don't take a caption or cover, so the UI says so and offers
  "Copy caption".
- Design: the existing tokens/primitives, WCAG AA, keyboard + Esc, reduced motion, phone layouts.

## Review Focus
1. A manual post time on an `approved` video survives the scheduler's next tick and reserves its slot → Task 2.
2. Two overdue locked videos publish one per tick and are never moved → Task 2.
3. An assistant reply that proposes an action for an id that doesn't exist is dropped, not shown → Task 4.
4. Clicking an old assistant action after the state changed (e.g. the job already finished) gives a clear error,
   not a crash → Task 5.
5. The assistant shows a calm message when Claude is at its limit (no API spend) → Task 4.

### Task 3: Video page edits (web)
**Files:** `apps/web/lib/actions.ts`
- `updateVideoTitle(id, title)`: 1–150 chars.
- `scheduleVideo(id, iso|null)`:
  - the time must be in the future and ≤ 60 days ahead;
  - status `ready` → also approve;
  - allowed only for `ready`/`approved`/`scheduled`;
  - sets `schedule_locked`;
  - null → unlock + `scheduled_for` null + status `approved` if it was `scheduled`.
- `setCover(id, ms)`: 0 ≤ ms ≤ duration, then enqueue `make_thumb`.

**Component:** `components/video-edits.tsx` with `VideoDetails` (title + post time) and `CoverPicker` (a range
slider that scrubs a hidden `<video>` preview, plus a Save cover button). `CaptionEditor` gains **Copy caption**,
plus the draft-mode note. The video page shows them. `lib/types.ts` adds `cover_ms` and `schedule_locked`.
`JOB_SPEC` gets `make_thumb`. The videos list shows the post time.

### Task 4: Assistant worker

  - `test_history_is_included`.

### Task 5: Assistant UI + action runner (web)
**Files:** `apps/web/lib/actions.ts`
- `sendAssistantMessage(text)`: max 2000 chars; inserts the user row + a pending assistant row + an
  `assistant_reply` job.
- `runAssistantAction(messageId, index)`: loads the stored action, re-validates it, maps it to the existing server
  action, and appends the result as an assistant row.
- `clearAssistant()`.

**Component:** `components/assistant.tsx`
- A floating button bottom-left (desktop `left-[248px]` beside the sidebar; phone above the bottom nav).
- A panel or sheet with messages, a typing state, suggested questions, Esc to close, and focus trap basics.
- It polls every 2 s while a reply is pending.

`app/(app)/layout.tsx` mounts it. `lib/data.ts` adds `getAssistantMessages(limit=40)`.

### Task 6: Channels grid + Edit
`app/(app)/channels/page.tsx`: cards in `grid-cols-1 md:grid-cols-2 xl:grid-cols-3`. Each card shows the colour
bar, name, niche, account, mode, posts/day, last post, 7-day views, status badge, toggle + Resume, and an **Edit**
button (`/channels/{slug}/settings`).
